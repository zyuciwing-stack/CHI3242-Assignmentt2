# 兩漢文論的西漢／東漢句級分類

以曹順慶主編《兩漢文論譯注》（北京：北京出版社，1988）為核心篇目清單，以嚴可均校輯《全上古三代秦漢三國六朝文》的《全漢文》《全後漢文》核查及補收，建立兩漢主流文論的句級語料，並用 jieba、詞語 TF-IDF 與邏輯迴歸判斷句子屬於西漢還是東漢。

>
> 互動探索分析（52 篇全庫 PCA、篇章相似度、重引候選）：[`output/exploration/index.html`](output/exploration/index.html)；研究發現見 [`output/exploration/research_findings.md`](output/exploration/research_findings.md)。
>
> 本倉庫不含姓名或學號。`report.md`／`report.pdf` 由作者依 `report_outline.md` 撰寫；本輪交付資料、程式、評估結果與報告提綱，未代寫報告正文。

## 1. 研究問題

在選定的兩漢主流文論中，邏輯迴歸能否從用詞辨認西漢與東漢的句子？它在哪些文類或篇章最容易判錯？

## 2. 標籤與單位

- 單位：一句。按底本句號、問號、感嘆號切句，保留原句與句序。
- `西漢`：依文字本身的成篇年代歸西漢。
- `東漢`：依文字本身的成篇年代歸東漢。
- 跨期或歸屬有疑問者另列，不進入訓練：
  - 《毛詩序》作者與成篇年代有爭議（舊題毛亨，或以為衛宏），列「歸屬未定」，只作獨立探針。
  - 桓譚歷西漢末、新莽、東漢初；《新論》定稿於東漢初，按成書歸東漢，另作「排除桓譚」敏感度檢查。
  - 《漢書·藝文志》為班固東漢編定，但詩賦略本劉歆《七略》，屬層累文本；正文歸東漢，分析時說明其西漢來源。
  - 《法言》採用傳統西漢歸類的操作口徑（成於西漢末年或新莽初年）。
- 模型輸入只用古文正文；曹本的題解、今譯、注釋未進入模型。

## 4. 語料與切句

### 4.1 清理規則

- 只取古文正文；刪除標題、編輯附註（〈…〉、〔…〕、（…）、【…】）、來源小註、卷末題識。
- 按 `。！？` 切句，保留原句與句序；句內引號保留於原句。
- 為建模另建 `text_normalized`：統一常見異體字（如 㠯→以、无→無、説→說、爲→為、敎→教、卽→即、旣→既、衆→眾、閒→間、脩→修 等），並移除引號；原句不改。
- 精確重複與近重（`SequenceMatcher` ≥ 0.90）去重，保留首次出現，記錄 `duplicate_of`。
- 排除過短句（少於 4 個漢字）、純目錄片段、編輯註、卷末題識；排除紀錄見 `data/excluded.csv`。
- 〈論衡·超奇〉整篇 129 句預留作獨立分析，不進入訓練／測試；就〈超奇〉與訓練、測試材料的重文檢查而言，僅 1 句近重（E02-063 對 E01-092，相似度 0.9167，已排除）。

|---|---|---:|---:|---:|---|---|---:|---:|---:|

- 全庫最大作者佔比偏高（v2 東漢王充 66.7%），故正式訓練採樣：
  - 每篇最多 80 句；
  - 每作者最多 160 句；
  - 若兩期句數比超過 1.25，再對較多一期隨機下採樣；
  - 隨機種子 42；再按標籤分層切 80% 訓練、20% 測試。

- 文類分布（v2 全庫／主樣本）與最大來源佔比詳見 [`output/sufficiency_check.md`](output/sufficiency_check.md)。

## 5. 方法

1. jieba 分詞（加入少量文論常用詞，如「文章」「著述」「鴻儒」「經傳」「詩賦」「離騷」等）。
2. 詞語 TF-IDF：`TfidfVectorizer(token_pattern=r"(?u)\b\w+\b", min_df=2, max_df=0.9, sublinear_tf=True)`；只在本輪訓練集擬合，測試集只 transform。
3. `LogisticRegression(max_iter=2000, random_state=42)`；主模型不使用停用詞、不用類別權重。
4. 主切分：`train_test_split(test_size=0.2, stratify=period, random_state=42)`；切分在 `data/dataset_v2.csv` 中固定，訓練腳本不再重切。
5. 對照：
   - v1：第一版核心篇目；
   - v2：加入《全漢文》／《全後漢文》補收；
   - full：全庫不設篇／作者上限；
   - grouped：同篇不跨訓練／測試（`GroupShuffleSplit`，按 `work_id` 分組）；
   - leave-author-out：訓練不含王充，測試全部王充篇章；
   - 變體：`class_weight=balanced`、`min_df=1`、1–2-gram、qhchina 0.2.7 `zh_cl_tr` 停用詞。
6. 停用詞若有使用，已核對 `qhchina 0.2.7` 的 `data/stopwords/zh_cl_tr.txt`（40 行）；主模型未用停用詞。

## 6. 主要結果

### 6.1 主模型（v2，主樣本）

- 測試 202 句：西漢 112、東漢 90。
- 主模型命中 **127/202**（0.6287）；若全部判西漢，多數類基準為 **112/202**（0.5545）。
- 主模型只比多數類基準多 15 句。
- macro F1 **0.6034**；weighted F1 **0.6143**。
- 混淆矩陣（列為預測，行為真實）：

|  | 預測西漢 | 預測東漢 |
|---|---:|---:|
| 真實西漢 | 89 | 23 |
| 真實東漢 | 52 | 38 |

| 類別 | 精確率 | 召回率 | F1 | 支持數 |
|---|---:|---:|---:|---:|
| 西漢 | 0.631 | 0.795 | 0.704 | 112 |
| 東漢 | 0.623 | 0.422 | 0.503 | 90 |

模型明顯偏向西漢：西漢召回率高，東漢召回率只有 0.422。

> leave-author-out 的測試全為單一作者（東漢），macro F1 受未出現的西漢類影響；解讀時以 accuracy／東漢 recall 為準。`leave_author_out_huantan` 與 `leave_author_out_huantan_balanced` 仍有王充訓練資料，故其〈超奇〉命中數不具獨立意義；這兩個 run 主要看 62 句桓譚的 accuracy／東漢 recall。

留一作者的原版與平衡版，訓練集兩期句數與東漢命中：

| run | 訓練西漢 | 訓練東漢 | 測試東漢 | 東漢命中 | accuracy |
|---|---:|---:|---:|---:|---:|
| 王充 原版 | 658 | 290 | 710 | 9 | 0.0127 |
| 王充 平衡版 | 658 | 290 | 710 | 176 | 0.2479 |
| 桓譚 原版 | 658 | 809 | 62 | 38 | 0.6129 |
| 桓譚 平衡版 | 658 | 809 | 62 | 28 | 0.4516 |

王充留出時東漢是訓練集的少數（290/948），`class_weight=balanced` 提高東漢命中（9→176）；桓譚留出時東漢是多數（809/1467），`class_weight=balanced` 反而降低東漢命中（38→28）。

- **v1 與 v2** 的隨機句級準確率相近（0.64／0.63）；v2 資料更完整，但在這一切分下，加入更多書錄、序跋後東漢召回率反而下降（不排除切分噪聲）。v1 的〈超奇〉69/129 也高於 v2 的 49/129。
- **full** 的 0.7451 與〈超奇〉108/129 不能當作一般化證據：全庫東漢類有 66.7% 是王充，模型等於見過大量王充文字；按篇／作者上限後，〈超奇〉降至 49/129。
- **grouped** 的 0.6684 與隨機切分相近；實際切分為 822 訓練／187 測試（81.5%／18.5%），測試集西漢 94／東漢 93；但《漢書·藝文志》20 句錯 17 句（85%）。此切分只保證同篇不跨訓練／測試，作者仍可能跨切分；更嚴格的作者層級檢查見 leave-author-out。即使同篇不跨切分，W06-015（法言·吾子，西漢）與 E11-018（漢書·藝文志，東漢）仍共享「詩人之賦麗以則，辭人之賦麗以淫」的引文；grouped split 把 W06 放訓練、E11 放測試，所以分組切分仍可能共享引文。
- **leave-author-out（王充）**：訓練完全不含王充時，710 句王充文字只有 9 句被判為東漢（1.27%），〈超奇〉只有 2/129；加 `class_weight=balanced` 後升至 176/710（24.8%），〈超奇〉32/129。這顯示結果會受作者、文類、來源與類別比例影響；現有設計難以分離各自的作用。對王充而言，結果可能受王充／《論衡》的詞彙影響，但無法據此排除文類與類別比例的作用。
- **leave-author-out（桓譚對照）**：訓練不含桓譚時，62 句桓譚仍有 38 句被判為東漢（61.3%）；加 `class_weight=balanced` 後為 28/62（45.2%）。跨作者泛化並非一律崩解；王充的 1.27% 不能推廣為所有東漢作者。

### 6.3 同作者留出篇章與探針

- 〈論衡·超奇〉129 句（東漢，與訓練同為王充，但整篇留出、未參與訓練／測試）：主模型 **49/129** 句判為東漢（0.380），平均 P(東漢)=0.469；多數句子被判為西漢。

### 可回讀的誤判例

1. **W05-020**（西漢，史記·屈原賈生列傳）→ 東漢，P(東漢)=0.648
   - 原句：「適長沙，觀屈原所自沈淵，未嘗不垂涕，想見其為人。」
   - 相關詞：`屈原(+0.864)`、`不(-0.419)`、`人(+0.156)`。
   - 「屈原」是最強的東漢特徵，因為東漢王逸《楚辭章句》大量論屈原；這是內容／來源線索，不是東漢文風。

2. **E33-022**（東漢，詩譜序）→ 西漢，P(東漢)=0.200
   - 原句：「紀綱絕矣。」
   - 相關詞：`矣(-1.321)`。
   - 單一虛詞把句子推向西漢，說明模型也會抓句末語氣詞。

3. **E24-002**（東漢，招隱士序）→ 西漢，P(東漢)=0.385
   - 原句：「昔淮南王博雅好古，招懷天下俊偉之士，自八公之徒，咸慕其德而歸其仁，各竭才智，著作篇章，分造辭賦，以類相從。」
   - 相關詞：`天下(-0.402)`、`歸(-0.226)`、`從(+0.201)`、`淮南(+0.119)`。
   - 「淮南」指向西漢淮南王／《淮南子》，模型把東漢王逸的序文誤判為西漢。

4. **W03-036**（西漢，報任少卿書）→ 東漢，P(東漢)=0.660
   - 原句：「《詩》三百篇，大底聖賢發憤之所爲作也。」
   - 相關詞：`詩(+0.464)`、`也(-0.142)`、`作(+0.085)`。
   - 「詩」在東漢王逸、鄭玄的序文中密集出現，於是西漢司馬遷論《詩》的句子被推向東漢。

5. **E03-010**（東漢，論衡·對作）→ 西漢，P(東漢)=0.408
   - 原句：「楊、墨之學不亂義，則孟子之傳不造；韓國不小弱，法度不壞廢，則韓非之書不為；高祖不辨得天下，馬上之計未轉，則陸賈之語不奏；眾事不失實，凡論不壞亂，則桓譚之論不起。」
   - 相關詞：`天下(-0.391)`、`之書(+0.175)`、`亂(+0.127)`、`廢(-0.105)`。
   - 王充的論辯句式與先秦、西漢子書相近，單靠詞袋難以分辨。

相關詞為該句 TF-IDF 值乘邏輯迴歸係數後絕對值最大的前幾個 token；正號推向東漢，負號推向西漢。完整表見 `output/v2/misclassified_examples.csv` 與 `.md`。

## 8. 如何重跑

環境：Python 3.12.10；套件見 [`requirements.txt`](requirements.txt)。以下指令以 `python` 代表該環境的直譯器。

```powershell
# 1) 取得《全漢文》《全後漢文》卷次（如尚未下載）
python scripts/fetch_quanwen.py
python scripts/fetch_extra.py

# 2) 整理工作副本與中繼資料
python scripts/prepare_raw.py

# 3) 切句、清理、去重、取樣、切分
python scripts/build_corpus.py

# 4) 主模型（v2）
python scripts/train_model.py --dataset data/dataset_v2.csv --output-dir output/v2 --run-name v2_main

# 5) 第一版、全庫、分組、留一作者與變體
python scripts/train_model.py --dataset data/dataset_v1.csv --output-dir output/v1 --run-name v1_main
python scripts/train_model.py --full --output-dir output/full --run-name v2_full
python scripts/train_model.py --dataset data/dataset_v2.csv --grouped --output-dir output/grouped --run-name v2_grouped
python scripts/train_model.py --leave-author-out 王充 --output-dir output/leave_author_out_wangchong --run-name leave_author_out_wangchong

# 6) 誤判分析與文件
python scripts/analyze_errors.py
python scripts/make_docs.py
python scripts/make_exclusions_doc.py
```

`data/dataset_v2.csv` 已含固定的 `split` 欄；`train_model.py` 只讀該欄，不會重新切分。TF-IDF 與模型只以 `split == train` 的句子擬合。

## 9. 檔案地圖

- `data/sources.csv`：逐筆選篇依據、曹本頁碼、全漢文／全後漢文核查、實際底本、修訂號、網址、斷代依據、狀態。
- `data/selection_basis.md`：上述資訊的可讀表，分開列「選篇依據」與「實際底本」。
- `data/sentences_all.csv`：所有候選句（含原句、正規化句、句序、作者、篇名、文類、來源、狀態、去重與排除原因）。
- `data/dataset_v1.csv`、`data/dataset_v2.csv`：兩版主訓練樣本（含 `split`）。
- `data/train.csv`、`data/test.csv`：v2 主模型的訓練／測試句。
- `data/excluded.csv`：過短、重複、目錄片段等排除紀錄。
- `data/exclusions.md`：排除原因統計、重複引文與目錄片段的可讀表。
- `data/uncertain.csv`：歸屬未定的《毛詩序》句。
- `data/pending.csv`：已定位但待核／未收篇目。
- `data/raw/`：逐篇原文副本與修訂號中繼資料；`data/_inspect/` 為下載與查核工作紀錄。
- `data/raw_manifest.json`、`data/quanwen_fetch_log.json`、`data/extra_fetch_log.json`：下載與修訂號紀錄。
- `scripts/`：下載、整理、切句、訓練、評估、文件生成腳本；`scripts/_*.py` 為探索與下載工作紀錄。
- `output/README.md`：`output/` 檔案索引。
- `output/v2/`：主模型評估、混淆矩陣、逐句測試預測、留出篇章預測、誤判例。
- `output/v1/`、`output/full/`、`output/grouped/`、`output/variants/`、`output/leave_author_out_wangchong/`、`output/leave_author_out_huantan/`：對照與敏感度結果。
- `output/leave_author_out_wangchong_balanced/`、`output/leave_author_out_huantan_balanced/`：留一作者＋`class_weight=balanced`。
- `output/leave_author_out_counts.md`／`.csv`：原版與平衡版的訓練兩期句數、測試東漢命中。
- `output/version_log.md`：所有版本的資料與結果摘要。
- `output/sufficiency_check.md`：句數、篇數、來源佔比與達標檢查。
- `output/error_analysis.md`：按文類、作者、篇章的錯誤率。
- `report_outline.md`：報告提綱與可引用數字。

## 10. 限制

- 語料仍小，且文類／作者與分期高度混淆：東漢類由王充主導，西漢類由劉向書錄、司馬遷、揚雄分擔。所謂「分期」在一定程度上是「作者／文類」；類別比例也會影響決策邊界。
- 曹本與中華書局影印本頁碼未見原書，頁碼待核；實際底本為維基文庫轉錄，雖記錄修訂號，仍非紙本影印。
- 句內引號中的句號也會切句，產生一些以「曰：」開頭或引號不配對的片段；已用過短句與去重規則控制，但無法完全消除。
- 異體字正規化只覆蓋常見字形，未做全面校勘。
- TF-IDF ＋ 邏輯迴歸是線性詞袋模型，不能處理語法、典故、語義演變與長距離依賴。
- 分組切分與留一作者結果顯示：結果會受作者、文類、來源與類別比例影響，現有設計難以分離各自的作用；因此不應把 127/202 的結果解讀為「東漢文風可被穩定辨認」。
- 《毛詩序》的預測隨訓練配置變動，不能用來裁斷其作者或年代。
