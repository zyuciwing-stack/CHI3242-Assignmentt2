# 誤判例

## 西漢誤判為東漢

- **W03-029｜司馬遷〈報任少卿書（節選）〉**
  - 原句：今僕不幸，早失二親，無兄弟之親，獨身孤立，少卿視僕于妻子何如哉？
  - 真實／預測：西漢／東漢（P(東漢)=0.604）
  - 相關詞：無(+0.690); 哉(-0.182)
- **W03-049｜司馬遷〈報任少卿書（節選）〉**
  - 原句：故且從俗浮沈，與時俯仰，㠯通其狂惑。
  - 真實／預測：西漢／東漢（P(東漢)=0.601）
  - 相關詞：時(+0.288); 與(+0.189); 其(-0.183); 浮(+0.172); 以通(+0.029)
- **W25-017｜劉歆〈移書讓太常博士（節選）〉**
  - 原句：當此之時，一人不能獨盡其經，或爲《雅》，或爲《頌》，相合而成。
  - 真實／預測：西漢／東漢（P(東漢)=0.527）
  - 相關詞：不能(+0.211); 之時(-0.200); 雅(+0.141); 頌(+0.119); 或(-0.086); 為(+0.008)
- **W13-026｜劉向〈孫卿書錄〉**
  - 原句：至漢興，江都相董仲舒亦大儒，作書美孫卿。
  - 真實／預測：西漢／東漢（P(東漢)=0.577）
  - 相關詞：亦(+0.393); 董仲舒(+0.325); 相(-0.324)
- **W25-012｜劉歆〈移書讓太常博士（節選）〉**
  - 原句：《尚書》初出于屋壁，朽折散絕，今其書見在，時師傳讀而巳。
  - 真實／預測：西漢／東漢（P(東漢)=0.514）
  - 相關詞：尚書(+0.510); 而(-0.268); 在(-0.101)

## 東漢誤判為西漢

- **E30-024｜桓譚〈新論·正經〉**
  - 原句：王者造明堂辟雍，所㠯承天行化也。
  - 真實／預測：東漢／西漢（P(東漢)=0.272）
  - 相關詞：所以(-0.794); 也(-0.106)
- **E34-003｜應劭〈風俗通義序〉**
  - 原句：漢興，儒者競復比誼會意，爲之章句，家有五六，皆析文便辭，彌以馳遠；綴文之士，雜襲龍鱗，訓註說難，轉相陵高，積如丘山，可謂繁富者矣。
  - 真實／預測：東漢／西漢（P(東漢)=0.456）
  - 相關詞：儒者(-0.216); 矣(-0.170); 漢興(+0.166); 皆(+0.156); 可謂(+0.149); 辭(-0.139)
- **E34-021｜應劭〈風俗通義序〉**
  - 原句：犬馬旦暮在人之前，不類不可，類之故難；鬼魅無形，無形者不見，不見故易。
