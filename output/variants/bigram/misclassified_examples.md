# 誤判例

## 西漢誤判為東漢

- **W02-083｜司馬遷〈史記·太史公自序（節選）〉**
  - 原句：二十八宿環北辰，三十輻共一轂，運行無窮，輔拂股肱之臣配焉，忠信行道，以奉主上，作三十世家。
  - 真實／預測：西漢／東漢（P(東漢)=0.542）
  - 相關詞：忠信(+0.289); 道(-0.085); 作(+0.059); 行(-0.006)
- **W03-036｜司馬遷〈報任少卿書（節選）〉**
  - 原句：《詩》三百篇，大底聖賢發憤之所爲作也。
  - 真實／預測：西漢／東漢（P(東漢)=0.581）
  - 相關詞：詩(+0.328); 所 為(-0.123); 也(-0.102); 為(+0.068); 詩 三百(+0.062); 篇(+0.053)
- **W07-034｜揚雄〈法言·問神（節選）〉**
  - 原句：人病以多知爲雜，惟聖人爲不雜。」
  - 真實／預測：西漢／東漢（P(東漢)=0.565）
  - 相關詞：為(+0.350)
- **W05-020｜司馬遷〈史記·屈原賈生列傳（節選）〉**
  - 原句：適長沙，觀屈原所自沈淵，未嘗不垂涕，想見其為人。
  - 真實／預測：西漢／東漢（P(東漢)=0.637）
  - 相關詞：屈原(+0.819); 不(-0.387); 人(+0.129); 為(+0.109); 其(-0.020); 觀(+0.001)
- **W06-050｜揚雄〈法言·吾子（節選）〉**
