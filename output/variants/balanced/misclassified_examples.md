# 誤判例

## 西漢誤判為東漢

- **W02-083｜司馬遷〈史記·太史公自序（節選）〉**
  - 原句：二十八宿環北辰，三十輻共一轂，運行無窮，輔拂股肱之臣配焉，忠信行道，以奉主上，作三十世家。
  - 真實／預測：西漢／東漢（P(東漢)=0.609）
  - 相關詞：忠信(+0.306); 道(-0.119); 作(+0.102); 行(+0.035)
- **W03-036｜司馬遷〈報任少卿書（節選）〉**
  - 原句：《詩》三百篇，大底聖賢發憤之所爲作也。
  - 真實／預測：西漢／東漢（P(東漢)=0.701）
  - 相關詞：詩(+0.464); 也(-0.143); 作(+0.086); 為(+0.076); 所(+0.067); 之(+0.067)
- **W07-034｜揚雄〈法言·問神（節選）〉**
  - 原句：人病以多知爲雜，惟聖人爲不雜。」
  - 真實／預測：西漢／東漢（P(東漢)=0.598）
  - 相關詞：為(+0.281)
- **W05-020｜司馬遷〈史記·屈原賈生列傳（節選）〉**
  - 原句：適長沙，觀屈原所自沈淵，未嘗不垂涕，想見其為人。
  - 真實／預測：西漢／東漢（P(東漢)=0.687）
  - 相關詞：屈原(+0.854); 不(-0.423); 人(+0.154); 為(+0.088); 觀(-0.004); 其(-0.003)
- **W16-003｜劉向〈鄧析書錄〉**
  - 原句：好刑名，操兩可之說，設無窮之辭，當子產之世，數難子產爲政。
  - 真實／預測：西漢／東漢（P(東漢)=0.545）
  - 相關詞：之辭(-0.224); 操(+0.197); 可(-0.111); 好(+0.077); 之(+0.066); 說(+0.056)
